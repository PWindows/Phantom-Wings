# Phantom Wings

**Built for Minecraft, built for you.**



![Total Downloads](https://img.shields.io/github/downloads/pwindows/phantom-wings/total?style=flat&label=Total%20Downloads&labelColor=%23ffce02&color=%23ffffff)




![Latest Release](https://img.shields.io/github/v/release/pwindows/phantom-wings?style=flat&label=Latest%20Release&labelColor=%23ffce02&color=%23ffffff)



Phantom Wings is the server control plane for Phantom Panel, designed to be highly performant and secure. Wings provides an HTTP API allowing you to interface directly with running server instances, fetch server logs, generate backups, and control all aspects of the server lifecycle.

In addition, Wings ships with a built-in SFTP server allowing your system to remain free of Phantom specific dependencies, and allowing users to authenticate with the same credentials they would normally use to access the Panel.
